7Concurrency & Idempotency Rules

RuleRationale
OM may run shard migrations for different OS clusters concurrently.Maximize throughput across the fleet.
Only one shard migration at a time per OS cluster.MigrationCommand's R/W lock would otherwise hurt serving latency.
All RPCs (StartMigration, MigrateBatch, OnMigration, EndMigration) idempotent.Responses may be lost; retries must be safe.
OM exposes a migration-status gRPC (queried by admin/erdapel).Observability: how many shards migrated so far.
